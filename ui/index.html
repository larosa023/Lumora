Turn on RAM & motherboard lighting

RAM and motherboard lighting sit on a system bus that Windows only opens to programs with administrator rights. Lumora sets this up once:

  • Installs PawnIO, a small signed driver made for exactly this
  • Runs its hardware engine with full access each time you sign in

Windows asks for your permission one time. You won't see the prompt again.
